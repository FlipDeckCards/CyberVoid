# Dinosaurs (Feral 3.0)

A full 3D first-person wave-survival shooter set in *Hollow Reach*, an overgrown jungle park. Desktop first (Chrome on a decent PC); basic touch support.

* **Play:** `/feral3/` on the DEADZONE site.
* **Engine:** Three.js (bundled in `lib/three`, no CDN), PBR materials, HDR environment from a procedural night sky, ACES tone mapping with colour grading, a moonlight shadow map that follows the player, SSAO (Ultra), bloom, FogExp2 plus mist sheets, moonlight shafts, swaying instanced foliage, particles, decals, a pool of flickering lights, a flashlight (F).
* **Rules:** `js/data.js` and `js/sim.js` are pure (no DOM) and run in Node for the tests. The map is a tile grid (2 m tiles): creatures path-find with a flow field (the grid equivalent of a navmesh; big creatures use a clearance-aware field), the player is pushed out of anything solid.
* **Models:** `models/*.glb` are optimised copies of the supplied models (see `tools-feral3/ASSET-REPORT.md`). `models/manifest.json` lists sizes and LODs. To replace a model, run `node tools-feral3/optimize.js stage1 <id>` then `stage2 <id>` (reads the originals from `C:\IMAGES FOR 3D`, never modifies them).
* **Textures:** all procedural, generated by `tools-feral3/make-textures.js` into `textures/`.
* **Sound:** `audio/manifest.json` + `audio/README.md` (drop in real files, no code changes). Until then every sound is synthesised in code.
* **Tests:** `node tools-feral3/map-test.js`, `rules-test.js`, `rules-trap-test.js`, `sim-test.js [seeds] [rounds]`; in the browser `tools-feral3/browser-test.js` (keyboard + mouse, simulated PlayStation and generic pads, simulated touch, menus).

## Controls
Keyboard + mouse: WASD, mouse look (click to capture), left click shoot, right click aim down sights, Shift sprint, Ctrl or C crouch, R reload, E use / hold to repair, Q or wheel or 1-3 swap, F flashlight, Esc pause.
PlayStation controller: sticks, R2 shoot, L2 aim, L3 sprint, Circle crouch, Square reload, Cross use, Triangle swap, D-pad up flashlight, Options pause. Other pads work too.
Touch: floating left stick, drag right side to look, FIRE / RELOAD / USE / SWAP buttons.

## Graphics quality
Settings > Graphics quality: Auto (Ultra on a strong desktop, High / Low on weaker devices and phones, with a frame-rate governor that lowers the render resolution if needed), Ultra, High, Medium, Low.
